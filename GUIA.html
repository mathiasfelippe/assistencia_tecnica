1. O que você precisa ter instalado

  • Python 3.10 ou mais novo. Para conferir, digite python --version no PowerShell.
  • MySQL Server 8 funcionando, e a senha do usuário root.
  • MySQL Workbench, para criar o banco e fazer o DER.

2. Extrair o projeto

  1. Clique com o botão direito no arquivo .zip e escolha Extrair tudo… → Extrair.
  2. Dentro da pasta extraída você vai ver: a pasta sistema, o arquivo assistencia_db.sql, o der.png/der.pdf, a documentação e este guia.

3. Instalar as dependências do Python

  1. Abra a pasta sistema. Clique na barra de endereço do Explorador de Arquivos, digite powershell e aperte Enter. O PowerShell abre já dentro dessa pasta.
  2. Rode: 
    pip install -r requirements.txt
    Isso instala o Flask (servidor web), o bcrypt (criptografia de senha e CPF) e o mysql-connector-python (conexão com o MySQL).
Você só precisa fazer isso uma vez em cada computador.

4. Criar o banco de dados

O arquivo assistencia_db.sql cria o banco assistencia_db com as 5 tabelas e 3 registros de teste em cada uma.

Opção A — pelo MySQL Workbench (mais fácil)

  1. Abra o Workbench e entre na conexão Local instance MySQL80 com a sua senha.
  2. Menu File → Open SQL Script… e escolha o assistencia_db.sql.
  3. Clique no raio ⚡ (Execute) para rodar o script inteiro.
  4. No painel Schemas, à esquerda, clique em atualizar (🔄). O banco assistencia_db vai aparecer.

Opção B — pelo PowerShell

Na pasta onde está o assistencia_db.sql:

cmd /c "mysql -u root -p < assistencia_db.sql"

Ele pede a senha do root. Se der “mysql não é reconhecido”, use o caminho completo:

cmd /c "\"C:\Program Files\MySQL\MySQL Server 8.0\bin\mysql.exe\" -u root -p < assistencia_db.sql"
Atenção: o script começa com DROP DATABASE IF EXISTS assistencia_db. Se você rodar de novo, o banco é apagado e criado do zero, e os dados que você cadastrou se perdem.

5. Iniciar o sistema

  1. Abra o PowerShell dentro da pasta sistema. É a pasta que tem o app.py.
  2. Informe a senha do seu MySQL e inicie o sistema, tudo numa linha: 
    $env:DB_PASSWORD="SUA_SENHA_DO_MYSQL"; python app.py
  3. Quando aparecer Running on http://127.0.0.1:5000, abra no navegador: 
    http://localhost:5000
  4. Para parar o sistema, aperte Ctrl + C no PowerShell.

Para testar só a conexão com o banco, sem abrir o site:

$env:DB_PASSWORD="SUA_SENHA_DO_MYSQL"; python testar_conexao.py

O resultado esperado é Conexão OK: {'banco': 'assistencia_db', 'versao': '8.x'}.

7. Gerar o DER no MySQL Workbench

  1. Com o banco já criado, vá em Database → Reverse Engineer…
  2. Escolha a conexão local, clique em Next e digite a senha.
  3. Marque o schema assistencia_db e vá clicando em Next até Execute → Finish.
  4. O diagrama aparece com as tabelas ligadas pelas chaves estrangeiras. Arraste as tabelas para organizar.
  5. Para exportar, use File → Export → Export as PNG… e salve como der.png.

Relacionamentos que devem aparecer:

  • clientes 1 — N aparelhos (um cliente pode ter vários aparelhos)
  • aparelhos 1 — N agendamentos (um aparelho pode ter vários reparos agendados)
  • servicos 1 — N agendamentos (um serviço pode estar em vários agendamentos)
  • usuarios fica sozinha: guarda só quem faz login no sistema

Back-end em Python (pasta sistema)

ArquivoPara que serve
app.pyPonto de entrada. Cria o app Flask, configura a sessão (cookie seguro, 30 min) e sobe o servidor na porta 5000. É ele que você roda com python app.py.
db.pyConexão com o MySQL. Lê DB_HOST, DB_USER, DB_PASSWORD e DB_NAME das variáveis de ambiente (padrão: localhost, root, sem senha, assistencia_db). Tem as funções query (SELECT) e execute (INSERT/UPDATE/DELETE), que usam parâmetros %s contra SQL Injection, e a classe ErroNegocio para as mensagens de erro.
autenticacao.pyLogin e sessão: gera e confere hashes bcrypt (usados na senha e no CPF), valida usuário e senha, inicia a sessão com o nome do usuário e controla a expiração de 30 minutos (EXPIRACAO_SEGUNDOS).
rotas.pyTodas as URLs do sistema. Bloqueia quem não está logado, entrega as páginas HTML e tem a API JSON: /api/login, /api/logout, /api/me (nome do usuário logado), /api/teste-conexao, /api/servicos e o CRUD genérico /api/clientes, /api/aparelhos e /api/agendamentos.
clientes.pyRegras de clientes: valida nome, e-mail e CPF (11 dígitos, sem repetir), guarda o CPF só como hash (LGPD), faz a busca por nome, e-mail, telefone ou CPF, e cadastra, edita e exclui (não deixa excluir cliente com aparelho).
aparelhos.pyRegras de aparelhos: valida IMEI (15 dígitos, único), marca, modelo e defeito, e exige um cliente já cadastrado. A listagem faz JOIN com clientes para mostrar o nome do dono. Não deixa excluir aparelho com agendamento.
agendamento.pyRegras de agendamentos: lista ordenada por data com todos os dados do cliente, do aparelho e do serviço (JOIN de 4 tabelas), cria agendamento, reagenda (muda a data e o status) e exclui. Também lista os serviços.
testar_conexao.pyScript rápido para testar se o Python consegue conectar no MySQL.
requirements.txtLista das bibliotecas Python: Flask, bcrypt e mysql-connector-python.
ROTEIRO.mdRoteiro original do professor, com o passo a passo e os testes esperados.
